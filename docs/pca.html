Principal Component Analysis

If you came to this tab looking for Pete Crow-Armstrong data, I'm sorry to disappoint

Overview

Principal Component Analysis (PCA) simplifies high-dimensional feature spaces by projecting data onto orthogonal principal components, mitigating multicollinearity and the "curse of dimensionality" in baseball tracking environments. The mathematical process involves data centering, constructing a covariance matrix, and performing eigenvalue decomposition to rank components by variance.

Data Prep

Features are continuous, normalized via Z-scores, and filtered using a minimum challenge opportunity threshold of 100 to isolate robust situational tracking rates for batters and catchers. Target performance fields are withheld during the fit to ensure structural habits drive the projections. Access full datasets via the project repository links.
